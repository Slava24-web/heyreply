# heyreply — учёт откликов на вакансии

Личный кабинет соискателя: отклик вносится за 10 секунд, а дашборды показывают, какие площадки, должности, локации и зарплатные вилки приводят к интервью и офферам.

Техническое задание: [docs/TZ.md](docs/TZ.md).

## Стек

| Часть | Технологии |
|---|---|
| `apps/web` | Next.js 16 (App Router, `proxy.ts`), React 19, Tailwind CSS 4, TanStack Query, Radix UI, cmdk, Recharts, next-intl, next-themes, Motion |
| `apps/api` | NestJS 11, Prisma 7 (`@prisma/adapter-pg`), PostgreSQL, JWT (access + refresh с ротацией), argon2, Zod, Swagger |
| `packages/shared` | Общие Zod-схемы, enum статусов, DTO, правила нормализации и определения источника по URL |

## Быстрый старт (локально)

Нужны Node 22+, pnpm и PostgreSQL. Ниже — вариант с локальным кластером Postgres в папке проекта (порт 5433). Можно взять и `docker compose up postgres`.

```bash
pnpm install
```

```bash
initdb -D .pgdata -U heyreply --auth=trust -E UTF8 && pnpm db:start && createdb -h localhost -p 5433 -U heyreply heyreply
```

```bash
cp apps/api/.env.example apps/api/.env
```

```bash
pnpm --filter @heyreply/shared build && pnpm db:migrate && pnpm db:seed
```

```bash
pnpm dev
```

- Веб: http://localhost:3000
- API: http://localhost:4000/api/v1, Swagger: http://localhost:4000/api/docs

Сид создаёт демо-пользователя с 150 откликами за полгода. Логин и пароль указаны в шапке [apps/api/prisma/seed.ts](apps/api/prisma/seed.ts) (только для локальной разработки).

## Docker

Секреты берутся из `.env` в корне (шаблон — `.env.example`). Без них compose не запустится:

```bash
printf "POSTGRES_PASSWORD=%s\nJWT_ACCESS_SECRET=%s\nHTTPS_ENABLED=false\nCOOKIE_SECURE=false\n" "$(openssl rand -hex 24)" "$(openssl rand -base64 48 | tr -d '\n')" > .env && chmod 600 .env
```

```bash
docker compose up -d --build
```

```bash
docker compose exec -u root api node_modules/.bin/ts-node --transpile-only prisma/seed.ts
```

Поднимаются четыре контейнера: Postgres, API (миграции применяются при старте, healthcheck по `/api/health`), веб и edge-прокси Caddy. Приложение открывается на http://localhost:3000 через Caddy. Caddy отбрасывает клиентский `X-Forwarded-For`, поэтому IP-лимиты нельзя обойти подменой заголовка; в production замените в [deploy/Caddyfile](deploy/Caddyfile) `:80` на домен, чтобы Caddy сам выпустил TLS-сертификат, и выставьте `HTTPS_ENABLED=true`, `COOKIE_SECURE=true`. Все порты слушают только `127.0.0.1` (Postgres на 5434, чтобы не конфликтовать с локальной базой), контейнеры работают не от root. API не запустится в production с секретом короче 32 символов или с секретом из примеров.

Порты 3000 и 4000 те же, что у `pnpm dev`, поэтому одновременно запускать оба варианта нельзя.

## Расширение для браузера (автоимпорт откликов)

`apps/extension` — расширение Manifest V3 для Chrome и Firefox. Оно добавляет отклики в heyreply, когда вы откликаетесь на вакансию на одной из 26 площадок, и обновляет статусы со страниц «Мои отклики».

| Группа | Площадки | Статусы со страницы «Мои отклики» |
|---|---|---|
| Россия и СНГ | hh.ru, Хабр Карьера, SuperJob, Getmatch, Авито Работа, Работа.ру, Зарплата.ру, Работа России, GeekJob, Djinni, Work.ua, Robota.ua | hh.ru (видит и отклики из мобильного приложения), Хабр Карьера |
| Международные | LinkedIn, Indeed, Glassdoor, ZipRecruiter, Monster, Wellfound, Welcome to the Jungle, Dice, StepStone, XING | LinkedIn, Indeed |
| ATS компаний | Greenhouse (включая формы, встроенные на сайты компаний), Lever, Workable, Ashby | — |

Статусы с площадок без страницы «Мои отклики» приходят через импорт из почты: приглашения, отказы и просмотры площадки присылают письмами.

**Что проверено на живых страницах** (`LIVE=1 pnpm --filter extension test`): hh.ru, Хабр Карьера, SuperJob, LinkedIn, Работа.ру, Зарплата.ру, Djinni, Wellfound, Dice, XING, Greenhouse, Lever, Ashby. Авито, Работа России, Work.ua, Robota.ua, Glassdoor, ZipRecruiter, Monster, StepStone, Welcome to the Jungle, Workable, GeekJob и Indeed не отдают страницы запросам не из браузера, поэтому адаптеры для них написаны по публичной схеме адресов и разметке schema.org и проверены только синтетическими тестами.

```bash
pnpm ext:build
```

В Chrome откройте `chrome://extensions`, включите режим разработчика и выберите «Загрузить распакованное» → `apps/extension/dist`. В Firefox: `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» → `apps/extension/dist/manifest.json`. Затем создайте токен в «Настройки → Интеграции» и вставьте его в окно расширения вместе с адресом heyreply. Архив для публикации в магазинах собирается командой `pnpm ext:zip`.

**Почему расширение, а не API площадок.** hh.ru закрыл API для соискателей с 15 декабря 2025 года, а у LinkedIn, Хабр Карьеры, SuperJob, Getmatch и Indeed API для откликов соискателя нет. Расширение работает в вашем браузере и под вашей сессией, пароли от площадок сервису не передаются.

**Как устроено.** Данные вакансии берутся из разметки schema.org `JobPosting` (её площадки встраивают для поисковиков), затем из стабильных атрибутов вроде `data-qa` на hh.ru, и только потом из заголовков страницы. Факт отклика проверяется только в области самой вакансии: блоки «похожие вакансии» с пометкой «Вы откликнулись» игнорируются. Страницы «Мои отклики» разбираются по структуре: карточка — ссылка на вакансию — короткий статус. Правовые формы («ООО», «Inc.») из названий компаний убираются. Сервер узнаёт отклик по ID вакансии на площадке, привязывает вручную добавленный отклик с той же компанией и должностью, двигает статус только вперёд, не трогает выставленные вручную итоговые статусы и не восстанавливает удалённые отклики. Если сервер недоступен, отклики копятся в очереди расширения и отправляются позже.

**Безопасность.** Токен интеграции (`otk_…`) показывается один раз, в базе хранится только его SHA-256. Токен отзывается в настройках и действует только на `/api/v1/import/*`. На этих маршрутах cookie игнорируются, поэтому подделать запрос с чужого сайта нельзя. Доступ к адресу сервера расширение запрашивает у пользователя при подключении.

**Ограничения.** Вёрстку страниц, доступных только после входа (кнопка после отклика, «Мои отклики»), я проверял на синтетических страницах с настоящими URL, а не на реальных аккаунтах. Вёрстку Indeed проверить не удалось вовсе: сайт блокирует запросы не из браузера. Если площадка поменяет разметку, поправить нужно `apps/extension/src/content/platforms.ts`.

## Импорт из почты (Cloudflare Email Routing)

Площадки присылают письма об отклике, просмотре, приглашении и отказе. Пользователь включает автопересылку этих писем на личный адрес вида `in-<32 hex>@<домен>`, и отклики со статусами появляются сами, в том числе отправленные с телефона. Цепочка: почта площадки → фильтр в Gmail, Яндексе или Mail.ru → Cloudflare Email Routing (catch-all) → `apps/email-worker` → `POST /api/v1/inbound/email` → тот же импорт, что у расширения.

**Настройка (один раз):**
1. Добавьте домен (или поддомен, например `in.example.com`) в Cloudflare и включите Email Routing: Cloudflare сам пропишет MX- и SPF-записи.
2. Сгенерируйте общий секрет и задайте API `INBOUND_EMAIL_DOMAIN` и `INBOUND_SECRET` (в `.env` для Docker или `apps/api/.env` для разработки):
```bash
openssl rand -hex 32
```
3. В [apps/email-worker/wrangler.toml](apps/email-worker/wrangler.toml) укажите публичный адрес heyreply (`HEYREPLY_API_URL`), затем разверните воркер и сохраните тот же секрет:
```bash
pnpm --filter email-worker deploy
```
```bash
cd apps/email-worker && npx wrangler secret put INBOUND_SECRET
```
4. Cloudflare → Email → Email Routing → Routing rules → Catch-all address → действие «Send to a Worker» → `heyreply-email-import`.
5. В heyreply: «Настройки → Интеграции → Импорт из почты» → «Получить адрес» и инструкции для Gmail, Яндекса и Mail.ru. Gmail пришлёт код подтверждения пересылки, и он появится прямо на этой странице.

**Безопасность.** Воркер подписывает каждый запрос HMAC-SHA256 (метка времени, адрес получателя, SHA-256 письма). API отклоняет неподписанные запросы, запросы с чужой подписью и устаревшие больше чем на 5 минут. Письмо площадки импортируется, только если у него есть действительная подпись DKIM домена этой площадки: автопересылка её сохраняет, а подделанное «приглашение» от постороннего её не пройдёт. Письма с кодом подтверждения пересылки тоже принимаются только с подписью Google, Яндекса или Mail.ru, и в интерфейсе показываются только ссылки на их домены. Адрес случайный (128 бит), его можно сменить: старый сразу перестаёт работать. Повторно доставленное письмо распознаётся по Message-ID. Тела писем не хранятся, в журнале остаются только отправитель, тема и результат (последние 200 писем за 90 дней).

**Ограничения.** Точных шаблонов писем площадок в открытом доступе нет, поэтому разбор эвристический (русский, украинский, английский, немецкий и французский): ссылка на вакансию (в том числе завёрнутая в трекер переходов), название вакансии из текста ссылки или кавычек в теме, компания по ссылке на работодателя или формулировкам («Компания X просмотрела…», «sent to X», «viewed by X»), статус по теме письма. Письма ATS обычно не содержат ссылку на вакансию. Для них отклик опознаётся по компании и должности, и сервер связывает его с тем же откликом, если расширение записало его с настоящим ID вакансии. Подборки и рассылки вакансий («Новые вакансии для вас», «Jobs for you») отсекаются по теме и никогда не становятся откликами. Нераспознанные письма видны в журнале как «Не распознано»: по ним шаблоны можно донастроить в [mail-parser.ts](apps/api/src/inbound/mail-parser.ts). Письма, пересланные вручную кнопкой «Переслать», не принимаются: подпись площадки при этом теряется.

## Как устроено

**Авторизация.** Access JWT (15 мин) и refresh (30 дней, в БД хранится только SHA-256) лежат в httpOnly-cookie. Next.js проксирует `/api/*` на Nest, поэтому cookie первосторонние и CORS в браузере не нужен. Refresh ротируется при каждом обновлении. Повторное использование старого токена отзывает все сессии пользователя. `proxy.ts` делает только оптимистичную проверку по маркерной cookie `has_session`, а настоящая проверка токена идёт в API. Клиент обновляет токен сам: одним запросом на все одновременные 401.

**Быстрый ввод.** Обязательны только компания и должность. Клавиша `N` или `⌘K` открывает форму. Комбобоксы предлагают значения из справочника: сначала совпадения по началу, потом по началу слова, потом по вхождению; внутри групп сортировка по частоте использования. Если совпадения нет, можно создать новое значение. Enter выбирает подсказку и переводит фокус дальше, Enter в обычном поле сохраняет, Shift+Enter сохраняет и очищает форму для следующего отклика. Источник определяется по домену ссылки. Черновик хранится в localStorage. Если в ту же компанию на ту же должность уже был отклик за 30 дней, появляется предупреждение.

**Метрики.** Каждая смена статуса пишется в `StatusHistory`. Для каждого отклика денормализованы `maxStage` (максимальный этап воронки) и `firstResponseAt` (первый ответ компании; отказ тоже считается ответом). Формулы — в [apps/api/src/analytics/metrics.ts](apps/api/src/analytics/metrics.ts). Группы меньше 10 откликов помечаются «Мало данных» и не участвуют в автоматических наблюдениях.

**Палитра.** Синий, зелёный, оранжевый, жёлтый и коричневый не используются: только слива, орхидея, фуксия, малиновый, винный, лаванда и графит. Категориальные цвета графиков (`--chart-1…4`) проверены валидатором для обеих тем: светлота, насыщенность, различимость при дальтонизме и контраст.
