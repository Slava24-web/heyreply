# Публикация расширения в Chrome Web Store и addons.mozilla.org

Аудитория международная: заполняйте листинг в первую очередь на **английском**, русскую локализацию добавьте вторым языком.

## Что указать

- **Политика конфиденциальности (URL):** `https://<ваш домен>/ru/privacy` (для международного листинга `/en/privacy`). Страница открывается без входа.
- **Сайт (homepage):** собирается из `HEYREPLY_SITE_URL`: `HEYREPLY_SITE_URL=https://<домен> pnpm ext:zip`.
- **Единственное назначение:** «Автоматически добавляет отклики пользователя на вакансии с сайтов поиска работы в его личный кабинет heyreply».

## Ответы на вопросы о данных (Chrome Web Store → Privacy practices)

| Вопрос | Ответ |
|---|---|
| Собираемые категории | «Website content» (название вакансии, компания, ссылка, место, зарплата, статус отклика) и «Authentication information» (личный токен интеграции, хранится локально) |
| Продаётся ли третьим лицам | Нет |
| Используется ли не по назначению | Нет, только для работы расширения |
| Используется ли для кредитных решений или рекламы | Нет |
| Куда отправляются данные | Только на сервер heyreply, адрес которого пользователь вводит сам |

Подтвердите соответствие «Limited Use» политике Chrome Web Store: данные используются только для функции, ради которой пользователь установил расширение.

## Обоснование разрешений

| Разрешение | Зачем |
|---|---|
| `storage` | Хранить токен, адрес сервера, очередь неотправленных откликов и настройки площадок локально |
| `alarms` | Повторить отправку, если сервер был недоступен |
| Content-скрипты на перечисленных площадках | Считать вакансию и статус отклика на страницах «Мои отклики» и при отклике. Другие сайты расширение не затрагивает |
| `optional_host_permissions: https://*/*` | Только по запросу пользователя: доступ к адресу его собственного сервера heyreply (адрес заранее неизвестен). Расширение запрашивает доступ к одному введённому адресу, а не ко всем сайтам |

## Текст листинга (оговорка)

Добавьте в описание: «Бесплатно, без подписок и рекламы; поддержать автора можно добровольным донатом: <ссылка из DONATE_URL>». На addons.mozilla.org ссылку на пожертвования укажите в отдельном поле «Contributions».

Добавьте в описание: «heyreply не связан с площадками поиска работы и не одобрен ими. Названия площадок принадлежат их владельцам. Условия некоторых площадок ограничивают автоматическое считывание страниц: вы сами решаете, для каких площадок включать расширение, и можете отключить любую в окне расширения».

## Чеклист перед отправкой
- [ ] Политика доступна по указанному адресу без входа и содержит раздел «Расширение для браузера»
- [ ] `LEGAL_*` заданы, на странице нет «[не указано]»
- [ ] Скриншоты не содержат реальных личных данных
- [ ] Сборка: `pnpm ext:zip`
